时光守护隐私政策使用帮助与反馈

我们在这里，听你反馈。

维护者：ccoolmans

反馈问题

请提供 App 版本、iOS 版本、发生问题的操作步骤、你期望看到的结果和实际结果。App 内“我的 → 意见反馈”可生成草稿。

前往 GitHub 提交反馈 →

需要 GitHub 账号。此渠道公开可见；不要提交家人姓名、健康信息、备份、账号密码或包含这些信息的截图。开发者不会通过此页面索要你的 Apple 密码或验证码。

通知没有出现

  1. 在系统设置中允许时光守护通知，检查专注模式和通知摘要。
  2. 任务提醒需选择未来时间；完成、删除或取消提醒后不会继续安排该任务通知。
  3. 1.3.0 已移除健康知识与新闻通知。升级会清理旧版内容通知，任务提醒保留。
  4. 系统可能延迟通知，App 不能保证精确到秒的到达时间，不适合作为服药等关键事项的唯一提醒。

数据与备份

档案仅存于当前设备，不自动跨设备同步。请在“我的 → 备份与恢复 → 导出当前备份”保留自己的副本。恢复备份会替换当前档案，并关闭导入任务的提醒，避免意外重复；需要时请重新开启。设备上的备份不替代你自行导出的副本。

遇到读取异常

先不要卸载 App。界面会提供重新读取、使用有效备份恢复或导出恢复资料的选项。恢复资料含私人数据，请妥善保管，不要贴到公开反馈页面。

购买与退款

若通过 App Store 购买，退款申请由 Apple 处理，可访问 Apple 问题报告页面。开发者不能直接代 Apple 批准退款。
