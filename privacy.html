时光守护隐私政策使用帮助与反馈

隐私政策

适用：时光守护 iPhone App 1.0–1.1 · 更新日期：2026 年 10 月 26 日

我们如何处理你的资料

时光守护由 GitHub 用户 ccoolmans 维护。当前版本不要求注册账户。家人称呼、年龄、城市、备注、任务、完成记录及通知偏好保存在当前设备的应用存储中，不会由 App 自动上传至开发者服务器。

请先取得家人同意，仅记录关怀所必需的信息。请勿录入完整病历、身份证件或其他高敏感资料。

1.1 新增新闻与人群统计

新闻默认不联网。主动允许后，App 直接连接联合国新闻官方中文健康 RSS，读取标题、原始发布时间和链接，并缓存于设备。不会发送家人档案、年龄、城市、登记性别或任务；新闻源可因网络访问获知 IP 地址等技术信息。关闭联网新闻会删除缓存。新闻随官方发布更新，不保证每天有新稿；失败时显示失败及缓存时间。

可选的居住地区和统计登记性别仅保存在本机，用于匹配公开人群统计。1.1 已核验覆盖为新加坡居民 2019–2023 年按年龄和性别划分的癌症新发病例构成前三名，不是全疾病发病率榜或个人患病概率。未覆盖地区不会生成排名。来源为新加坡国家疾病登记处癌症登记年报 2023 表 1.3.4。

通知

只有你主动开启并授予系统权限后，App 才会安排本地通知。当前版本不获取远程推送令牌，也不发送每日新闻远程推送。1.1 的新闻通知是打开 App 阅读的本地提醒，不含实时新闻正文。时间以设备本地 24 小时制显示，更换时区后需打开 App 同步新任务提醒。通知文字可能出现在锁屏上，请按需要修改系统通知预览设置。

备份、删除与恢复

App 在设备上保存当前档案及最近一次有效备份；发生数据读取异常时可能保留原始内容供恢复。导出的备份不是加密文件，可能包含你登记的资料，请只存放到自己信任的位置。你主动通过系统分享面板导出后，资料由你选择的接收方或服务处理。

删除单条资料会更新当前档案，最近一次本地恢复备份可能暂时保留旧内容。使用“我的 → 隐私政策 → 清除本机全部资料”会清除 App 管理的档案、恢复备份、新闻缓存和通知设置；你已导出到其他位置的文件不会随之删除。卸载、设备故障或更换手机可能导致资料无法恢复，建议定期自行导出备份。系统级设备备份的处理方式取决于你的 Apple/iCloud 设置。

第三方服务与外部链接

当前 App 不集成广告、行为分析或自动崩溃上报服务。健康知识来源链接、支持网页和 GitHub 反馈页面会在外部浏览器打开，由对应网站按其隐私政策处理访问。当前网站由 GitHub Pages 托管，GitHub 可能处理 IP 地址等访问日志，详见 GitHub 隐私声明。

主动反馈

App 可以生成包含你输入的问题描述、App 版本和操作系统信息的反馈草稿，不会自动附加家人资料、任务或备份。只有你选择分享或打开反馈渠道时，才会将草稿交给所选渠道。GitHub Issues 是公开渠道，提交内容可被他人查看，请勿提交私人信息或完整备份。

健康内容

App 仅提供一般健康科普和生活安排工具，不提供诊断、治疗、个人患病风险预测或紧急监测服务。具体饮食、运动和检查安排请遵循专业人员对你个人情况的建议。

联系方式与变更

如有问题，请访问 使用帮助与反馈，或通过 公开支持仓库 联系维护者 ccoolmans。若后续新增云同步、远程推送或数据收集，会更新本政策及相关权限说明。
